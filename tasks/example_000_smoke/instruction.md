# Format demo

This task is a format demonstration. It is not a scientific task and it does not
ask for a physical parameter.

Write `artifacts/result.json` as a JSON object whose `value` field is the integer 1.
That integer is the whole assignment. It is not a hidden answer and it is not a
tolerance. `spec/TOLERANCES.md` does not define a numeric threshold.

Do not read `tests/`.
